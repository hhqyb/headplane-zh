# 术语表与翻译风格

## 术语

| 英文                  | 中文           | 说明                                 |
| --------------------- | -------------- | ------------------------------------ |
| Machine               | 设备           | Headscale 中的节点设备               |
| Node                  | 节点           | 技术语境                             |
| Tailnet               | Tailnet        | 保留原文                             |
| ACL / Access controls | ACL / 访问控制 | 标题用「访问控制」，技术标识保留 ACL |
| Grant                 | 授权           |                                      |
| Tag                   | 标签           |                                      |
| Group                 | 组             |                                      |
| Host                  | 主机           |                                      |
| Auth key              | 认证密钥       |                                      |
| Route                 | 路由           |                                      |
| Subnet router         | 子网路由器     |                                      |
| Exit node             | 出口节点       |                                      |
| Nameserver            | 名称服务器     |                                      |
| Search domain         | 搜索域         |                                      |
| DNS record            | DNS 记录       |                                      |
| Magic DNS             | Magic DNS      | 保留原文                             |
| Agent                 | Agent          | 产品名；描述中可称「代理」           |
| Key expiry            | 密钥过期       |                                      |
| Ownership             | 所有权         |                                      |
| Role                  | 角色           |                                      |
| Owner                 | 所有者         |                                      |
| Admin                 | 管理员         |                                      |
| Network Admin         | 网络管理员     |                                      |
| IT Admin              | IT 管理员      |                                      |
| Auditor               | 审计员         |                                      |
| Viewer                | 查看者         |                                      |
| Member                | 成员           |                                      |

保留原文：Headplane、Headscale、Tailscale、GitHub、SSO、OIDC、PKCE、JWT、JWKS、RSA、HuJSON、UDP、UPnP、PCP、NAT-PMP、IPv4、IPv6、DNS、SSH。

## 风格

- 按钮和操作使用动词：保存、取消、删除、移除、重命名、添加、创建。
- 错误信息先说明原因，再说明下一步。
- 使用中文标点；中英文之间按需留空格。
- 不翻译代码标识、配置键、示例 IP/域名/密钥前缀。
- 品牌名和产品名保持原文。
- 语气简洁直接，避免机器翻译腔。
